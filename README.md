# Aurea BI Solutions — vista previa

Maqueta interactiva para revisión visual.

- **Rediseño (versión actual):** https://aureabisolutions.github.io/ABIS-Web-Preview/
- **Versión anterior:** https://aureabisolutions.github.io/ABIS-Web-Preview/anterior/

Este repositorio contiene únicamente los archivos generados para visualizar la web. El proyecto fuente y su documentación se mantienen por separado.

La agenda, el formulario, el WhatsApp y el Radar funcionan en modo demostración. No se envían solicitudes, correos ni reservas reales, y los datos de contacto, casos y paquetes son de muestra.
